口径说明

    
• 点位编号 / 单号 / 回执号唯一，重复存不进去（DB 唯一约束兜底）
• 档期按 ISO 周（周一至周日），同屏同周只挂一张画面
• 归属月按“发生日”落库固化（biz_period），跨月单不随查询日漂移
• 改错不抹记录：原单置“已对冲”、释放档期，另补对冲单挂同一根单
• 关闭后（落架/已对冲）的单据不能静默修改、不能回退
• 每步动作写事件留底：经手人、发生日、事件时刻、单据快照
• 外部回执挂回原单据；指向对冲单时回溯到根单
• 结算流程不在本轮范围
